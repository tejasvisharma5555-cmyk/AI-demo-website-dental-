# Platform knowledge cache

One file per platform or business type, written after researching it so the next build starts from here instead of from scratch.

- `platforms/<platform>.md` — e.g. `platforms/vapi.md`, `platforms/retell.md`, `platforms/twilio.md`
- `industries/<business-type>.md` — e.g. `industries/dental.md`, `industries/hvac.md`

Every file starts with a `Last verified: YYYY-MM-DD` line. Re-check anything older than 90 days before relying on it.
